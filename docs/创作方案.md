# 《炉心融解》MV 创作方案

## 一句话

凌晨两点睡不着的镜音铃，把胸口里越烧越烫的“反应堆”一路带进真正的炉心；最后的读数揭晓：那颗炉心一直是她自己的体温。

## 核心构想

歌词里的核心意象是核聚变炉，也就是人造太阳。整支 MV 围绕一个反复出现的意象展开：**环**。

- 房间天花板上日本住宅常见的环形荧光灯
- 她的虹膜
- 墙上的钟面与齿轮
- 城市尽头那座托卡马克装置里旋转的等离子体环

镜头在这些“环”之间做形状匹配转场，把卧室、城市和炉心连成一条不断下潜的路线。

画面右下角时隐时现一组控制台读数（炉心温度、时刻、中性子束等）。温度从开头一路攀升到一亿开尔文、最终溢出；天亮后的最后一个读数落回 **36.5℃**——反应堆是她的身体，她终于睡着了。结尾因此保持开放而不绝望。

## 三个世界

| 世界 | 内容 | 主色 |
| --- | --- | --- |
| 夜の部屋 | 六叠小屋、环形荧光灯、窗外整片夜景、没油的打火机 | 冷白荧光 + 窗外钠灯橙 |
| 街 | 俯瞰的城市光网格、车流光带、海湾边的聚变装置 | 深靛蓝 + 钠灯橙 |
| 炉心 | 环形真空室内壁、磁场线圈、流动的等离子体光带 | 契伦科夫蓝 → 白热 → 晨金 |

另有两段记忆插叙：过曝的“午后”（白色窗帘、强光）与“黄昏”（红日、外楼梯、融化的天际线）。

## 统一视觉语言：专色印刷与"烧穿"

全片每一帧都按小批量专色印刷处理：米色纸张、主墨以调幅网点铺出阴影，再叠一到三种专色，各色之间有轻微套印错位，纸纹每三帧"抖动"一次。镜音铃的黄色是贯穿全片的专色。

| 段落 | 纸 / 主墨 / 专色 |
| --- | --- |
| 夜（前奏、A 段、B2） | 米色纸 / 午夜蓝 / 铃黄、钠灯橙、青绿 |
| 白日梦（B1） | 白纸 / 暖灰 / 铃黄、青绿、淡粉 |
| 炉心（副歌） | 冷白纸 / 钴蓝 / 青、铃黄、紫 |
| 黄昏（A3、A4） | 粉米纸 / 酒红 / 红、橙、铃黄 |
| 桥段（钟、电视） | 新闻纸 / 黑，粗网点 |
| 激昂段 | 黑纸印红 |
| 虚空 | 黑纸印淡蓝 |
| 黎明与尾声 | 暖米纸 / 棕褐 / 金、天蓝 |

风格本身参与叙事：主歌是安静的"纸面"；副歌时炉心的光把纸烧穿——平时只有炉心最热的一点透光，每记军鼓把烧穿推开一圈，露出真实的辉光，洞口是平滑的有机轮廓和一道细细的焦边。炉心内景送印前略压暗，丝状等离子体保留墨色层次，不会印成一片空白。终副歌整页被烧尽进入黎明，尾声回到清晨的纸面。

歌词按背后画面的明暗换墨：落在暗处时印纸色，落在被光烧亮的地方时改用该段的主墨（炉心钴蓝、黄昏酒红、黎明棕褐），一句跨过明暗交界时就成为双色；专为亮底设计的句子（白日梦段的记号笔高亮）保持原色。

版式元素：开场、片头海报、间奏、白场与片尾带印刷裁切线、套准标记、专色色条和图纸式标题栏；"环"既是母题也是转场（灯环、瞳孔、炉心之间用圆形划像衔接）。

## 参考片的动态分析（千本樱、热异常）

方法：在浏览器里按 0.1 秒逐帧采样整片画面，计算相邻帧差得到剪辑点与运动强度；再对重点段落逐秒拼帧看画面如何随歌词变化；同时读了两部片子的高赞评论。

- **剪辑节奏跟着音乐能量走**：《千本樱》253 秒只有约 57 个硬切，副歌等高能段落切点密集（常见间隔 1–3 拍），平稳段落经常 20–30 秒没有硬切，靠连续运镜和画面内转场推进；运动强度几乎从不归零。
- **一句歌词一个画面**：唱到摩托的那一句出现摩托与巨大的字，唱到环线时樱花环→地图上的环线→塔身光环；《热异常》唱到黑色时黑太阳持续膨胀，唱到刺眼的那一句推到被闪光刺中的眼睛。歌词是画面里的图形（招牌、印章、挂幡、记号笔高亮），换句即换画。
- **形状呼应代替硬切**：环形、圆形在镜头之间传递，观众的视线有落点。
- **评论区的批评**：“切得太碎、闪屏太多”“需要一个主体视野来聚焦，周围的动效服务于焦点（主角的眼睛、字幕或歌词里提到的意象）”“堆料太多、没有中心”。被称赞的是“温度飙升时红通道先崩、字形再跟着错位”这类与音乐精确对位的细节。

据此对本片的调整：
- 保留并强化“一句一意象”：凌晨两点的数码钟、没油的打火机火花、阳台、上楼的脚步声（台阶逐拍亮起）、融化的城市、话语化作气泡、记忆碎片在炉心烧白、钟表与电视、乐谱与耳鸣；唱到人们一个个消失时城市灯光一盏盏熄灭，唱到空旷与寂静时从高空俯瞰无边黑暗里的一张床，唱到胸口堵住时胸口的炉心光环收紧。
- 歌词做成随演唱推进的图形：竖排句旁的铃黄色进度线按逐字时间填满；白日梦段用记号笔高亮扫出；副歌大字逐字砸入并带技术注记；桥段的笑声做成层层堆叠的回声，电视台词做成节目字幕条。
- 升温段落加入“红通道先滑移、字幕随后错位”的热失控效果；副歌里底鼓推镜、军鼓让套色错位，烧穿程度随音乐能量变化。
- 控制闪烁：频闪只在少数段落、频率低于每秒 3 次；主体始终明确——铃、她的眼睛、炉心光环或当句的意象。
- 桥段跟着歌声加速：先是二十秒只有钟表滴答的间奏（齿轮的擒纵轮、房间时钟的秒针都踩在这段滴答的拍点上），然后歌声以一两秒一个字的长音唱起秒针那一句，再逐渐唱快，画面在齿轮、凌晨两点的数码钟、电视和电视光里的铃之间交替，镜头长度从两小节缩到一小节、半小节、一拍，最后撞进满墙电视里饱和回响的笑声；底鼓保持轻微推镜。
- 电视里的人就是铃：唱到电视主持人那一句时，房间里的电视从雪花里调出台，主持人是举着话筒挥手、笑得过分完美的铃；反打是床上抱膝看着屏幕的真实的铃。下一句里，她是雪花里时隐时现的影子，满墙电视里的笑声也是她在笑。节目字幕条按电视的习惯整句先出，唱到哪个字哪个字点亮。
- 表情跟着歌词走，不复用不合适的旧素材：胃里像在灼烧时她捂着胃皱眉；梦见勒住你的脖子时她盯着自己摊开的双手；唱到含泪的眼睛时下眼睑含着泪；唱到被原谅的那一句时眼睑低垂、浅浅地笑；话语从干裂的唇间溢出时侧脸嘴唇微张，字从唇边被泡泡托走；喘不上气时她在炉心里捂着胸口仰起头；第二段副歌唱到记忆被融化时她垂着头、像要昏睡过去一样漂在白光里（第一段副歌是张开双臂仰望）；虚空段她睁着眼失眠，一行泪。
- 铃贯穿全片：前奏最后一小节是她手贴窗玻璃的背影，城市灯光在她身后化成散景，接第一句；黄昏那一段开始时她躺在床上睁着眼，夕照从脸上慢慢褪去——和片尾清晨她在同一位置熟睡的近景是同一个机位；唱到落日那一句时切到她哭肿的眼睛，青绿的瞳孔里倒映着城市和红色的落日。
- 结尾不落在空白的片尾卡上：最后一句唱完之后，清晨的房间里她其实还在。最后一个镜头俯拍枕头上的铃，在末小节的重拍上睁开眼、微笑，晨光随之亮起；片名和署名在余音里浮现在她身上，声音结束时一起淡出到黑。
- 切点全部落在拍点上：器乐段切在正拍；迎接人声的切点落在人声起句前的八分音符上。

## 视觉语言

- **镜头**：真实三维摄影机运动（推拉、升降、穿越），重拍点切换；段落之间用环形匹配、亮度闪白和连续穿越衔接，避免硬切跳跃。
- **歌词排版**：主歌用竖排明朝体逐字浮现；副歌用粗黑体大字，带热浪扭曲与发光；B2 的句子先排在铃的唇边，唱到的字被肥皂泡托起、上浮、破掉；C 段文字回声叠印；D 段做成乐谱式排版。字形从字体轮廓直接生成矢量路径，可以逐字变形、融化。
- **控制台界面**：细线、等宽字、日文技术标签，作为画框元素出现，而不是常驻遮挡画面。
- **角色**：镜音铃，标准造型——金色短发、大白蝴蝶结与白色发夹、青绿色眼睛、带麦克风的耳机、白色水手服配黄色领带。她的黄色与炉心的蓝色互为补色：钠灯、打火机火花和最后的日出都落在她的颜色上。生图只出中性光照的分层素材，在代码里按场景光重新上色、加轮廓光与颗粒，让她融入三维场景。镜头需要什么动作和表情就为它生成新的分层素材（共 27 个姿势与表情，另有 6 张眨眼用的闭眼版），替换旧表情时按双眼位置自动对齐，镜头构图不必重调。

## 制作方式

- 三维场景：Blender 5.2（Eevee，显卡渲染），全部由 Python 脚本程序化搭建。
- 角色：Codex 生图 → 抠层、分块 → 在 Blender 中作为可变形的分层平面驱动（呼吸、眨眼、发丝摆动）。
- 排版、读数与成片处理：Python（fontTools 字形 + skia 绘制 + numpy/OpenCV 合成）。
- 节奏：全曲是恒定的 165 BPM，十六分音符网格由鼓轨拟合（误差 ±6 ms），节拍特效都踩在这个网格上。歌词逐字对到音符：Demucs 分离人声后，用 MMS 强制对齐模型的字母概率、旋律音高和清辅音断声，把每个音拍放到网格上（V 家的辅音比音符提前 10–60 ms）；每个字在它的音符前约 0.07 秒开始出现，音符落下时完全显现。
- 输出：1920×1080，24 fps，H.264 高码率 + AAC。
