# input

Put the files you bring yourself here (they are not in the repository; see `src/paths.py`):

| file | what |
|---|---|
| `song.m4a` | the song (any format ffmpeg reads) |
| `lyrics.txt` | the lyrics, one sung line per line, a blank line between stanzas |
| `karaoke.ass` | optional: a karaoke file timed by ear (`{\k}` syllables), only to re-align the lyrics |
| `lrc/` | optional: LRC files to cross-check line starts |
